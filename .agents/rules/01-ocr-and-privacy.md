# Rule 01: OCR and Privacy

Applies to `backend/ocr_scrub.py` and anything that handles report images or text.

## 1. Image Pre-processing (OpenCV)

Implement `preprocess(image_bytes) -> np.ndarray` in this order:

1. Decode with `cv2.imdecode`. If the longest side is below 1500 px, upscale 2x (`INTER_CUBIC`).
2. Convert to **grayscale**.
3. Light denoise: `cv2.fastNlMeansDenoising` or a median blur (kernel 3).
4. **Adaptive thresholding**: `cv2.adaptiveThreshold(..., ADAPTIVE_THRESH_GAUSSIAN_C, THRESH_BINARY, 31, 15)` to remove shadows.
5. **Deskew**: estimate the angle with `cv2.minAreaRect` on the text pixels (`np.column_stack(np.where(img < 128))`). Normalise the angle and rotate with `cv2.warpAffine`. Skip if |angle| < 0.5 degrees.
6. PDFs: render each page with PyMuPDF at 300 DPI into an image, then run the same pipeline per page.

If the pytesseract call fails, set `pytesseract.pytesseract.tesseract_cmd` from the `TESSERACT_CMD` env var.

## 2. Row-Aware OCR (keep columns on one line)

Never use plain `image_to_string`. Use `pytesseract.image_to_data(img, config="--psm 6", output_type=Output.DICT)`.

1. Drop words with `conf < 30` or empty text.
2. Compute each word's vertical centre: `y_c = top + height / 2`.
3. Sort words by `y_c`. Start a new row when the gap to the previous word's `y_c` exceeds `0.6 * median_word_height`.
4. Inside each row, sort by `left` and join with a single space (or `|` when the horizontal gap is large).
5. Return `list[str]`, one string per visual row, so **Test Name, Value, Unit and Reference Range stay together**.

Add `parse_rows(lines) -> list[dict]` that extracts `{test_name, observed_value (float), unit, ref_range}` using regex.

- Unparseable lines are kept in a `raw_unparsed` list and still sent to the analyzer.
- Handle decimals carefully. Never silently drop or shift a decimal point.
- Normalise common OCR confusions only inside numeric tokens (`O`→`0`, `l`→`1`, `,`→`.`).

If average OCR confidence is below 55, return a flag `low_quality=True`. The bot must then ask the user for a clearer, straight-on photo instead of analysing.

## 3. Best-Effort Local PII Scrubbing (BEFORE any Gemini call)

Implement `scrub_pii(lines: list[str]) -> list[str]` in Python only. No external API is involved.

Remove or replace with `[REDACTED]`:

- **Patient name**: lines or fields labelled `Name`, `Patient`, `Patient Name`, `Mr.`, `Mrs.`, `Ms.`, `Smt.`, `Shri`, `S/o`, `D/o`, `W/o`, `C/o`
- **Phone numbers**: `(\+?91[\-\s]?)?[6-9]\d{9}` and landline patterns
- **Email**: standard email regex
- **Address**: lines with `Address`, `Addr`, `Pin`, `PIN`, `Road`, `Street`, `Nagar`, `Layout`, and 6-digit pincodes `\b\d{6}\b`
- **Lab, hospital and ID numbers**: `UHID`, `MRN`, `Lab No`, `Sample ID`, `Reg No`, `Barcode`, `Bill No`, `Visit ID`, `Accession`
- **Doctor name**: `Dr.`, `Ref. by`, `Referred by`, `Consultant`, `Pathologist`, `Signature`
- **Header and footer boilerplate**: accreditation text (`NABL`, `ISO`, `CAP`), websites, `Page x of y`, `Printed on`, QR text

**Retain** (clinical context): `Age`, `Sex`/`Gender`, and the biomarker rows. Extract age and sex into separate fields for the prompt.

Rules:

- Scrub per line, not per document, so a lab value is never removed by a greedy regex.
- Keep a unit test (`tests/test_scrub.py`) with dummy reports containing fake names, phones and IDs. Assert none survive.
- UI wording must be **"Personal details removed (best effort)"**. Never say "guaranteed" or "100% private".
- Add a bot message line asking the user to glance at the original and not forward screenshots of the full report.
- After scrubbing, the original image and raw text are deleted from memory and never written to disk or the DB.

## 4. DPDP Act 2023 Handling

- **`/delete` Telegram command**: asks for confirmation, then deletes the user row in Supabase. `ON DELETE CASCADE` removes their `reports` and `biomarkers`. Reply with a confirmation message in the user's language.
- Also provide a `[🗑️ Delete My Data]` inline button that does the same.
- Store only: Telegram chat id, optional age and sex, preferred language, scrubbed structured results. Do not store images, raw OCR text or names.
- On first use, show a short consent message ("This explains reports in simple words. Your personal details are removed before AI analysis. You can delete your data anytime with /delete") and require a tap on `[✅ I agree]` before processing. Record the consent timestamp in `users.consent_at`.
- Ask for consent in a way that covers the person uploading on behalf of a relative.
